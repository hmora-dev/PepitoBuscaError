Easy public link mode

Use from another Wi-Fi network

Setup needed
Recommended for non-technical use

Close the app, open PowerShell in the project folder, run these commands, then come back here and copy the GPS link.

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass .\scripts\easy-public-gps-link.ps1
What the easy command does
  1. Finds cloudflared or ngrok.
  2. Creates a public HTTPS tunnel to this app.
  3. Sets APP_PUBLIC_BASE_URL automatically.
  4. Starts Spring Boot with only the public device link shown.
If no tunnel tool is installed
  1. Run the app on a public HTTPS server, or use a public HTTPS URL you already have.
  2. Set APP_PUBLIC_BASE_URL to that URL.
  3. Restart the app and copy the generated GPS link.
  4. The other device opens the permission page in the browser and taps Allow.

Remote access requirements

Limited network scope

Only use this feature with devices or users you are authorized to track. The device owner must open the private link, the browser must ask for permission, and the application does not bypass browser security. Public links should be treated as private tokens and should not be shared publicly.

This interface intentionally does not expose localhost or LAN tracking links for client devices. Configure APP_PUBLIC_BASE_URL with a public HTTPS origin such as an ngrok, Cloudflare Tunnel, or reverse proxy URL.

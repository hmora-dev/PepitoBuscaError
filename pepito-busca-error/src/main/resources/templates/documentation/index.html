Documentation

A clear page to explain the architecture and defend the project.

Architecture

Spring Boot MVC

The application uses controllers for routes, services for business logic, repositories for database access, and Thymeleaf templates for the interface.

Database

MySQL persistence

Companies, analyses, indicators, recommendations, and tracked devices are stored in MySQL through Spring Data JPA.

Risk model

Simple scoring

Selected indicators are converted into a score from 0 to 100 and classified as low, medium, high, or critical.

OSINT

Passive public footprint

The OSINT module collects authorized public DNS, mail, web/CDN metadata, TLS, and well-known file signals without aggressive scanning.

Geolocation

Owned devices only

The geolocation module stores the last known browser-reported position of devices that belong to the user and resolves a readable place label when possible.

Security roadmap

Production hardening

Authentication, roles, organization isolation, PDF reporting, scheduled scans, and real alerting are documented as future production improvements.

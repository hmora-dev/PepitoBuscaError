# AI Usage Statement

Artificial intelligence was used as a development assistant to improve the existing PepitoBuscaError project.

AI support was used for:

- organizing the MVC structure,
- drafting Java classes and Thymeleaf templates,
- improving CSS layout and visual consistency,
- preparing SQL scripts and documentation,
- checking that the project remains understandable for an academic defense.

The final project remains a traditional Spring Boot MVC application. The implemented functionality is based on local code, form input, JPA persistence, and MySQL data. No external AI service is required to run the application.

The student should review, understand, and be able to explain every part of the final code before presenting the project.

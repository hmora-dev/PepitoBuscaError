# Future Improvements

These features are planned improvements, not current implemented functionality.

## Security

- Session-based Spring Security login.
- Roles: `ADMIN`, `ANALYST`, and `VIEWER`.
- BCrypt password hashing.
- Organization or tenant ownership for all business data.
- CSRF protection on state-changing forms.
- Audit logs for sensitive changes.

## Reporting

- Executive and technical PDF report generation.
- CSV export for findings and recommendations.
- Company-level trend charts.

## Alerting

- Real alert delivery by email or webhook.
- Alert acknowledgement history.
- Notification preferences per organization.

## Scanning and OSINT

- Scheduled passive scans.
- More OSINT provider integrations.
- Provider enable/disable settings.
- Finding status update UI.
- Evidence retention settings.

## Geolocation

- Tracking token expiration.
- Tracking token regeneration.
- Retention policy for location data.
- Access control for tracking links.

## Quality

- More unit tests.
- More MockMvc controller tests.
- Repository integration tests.
- Production deployment guide.
